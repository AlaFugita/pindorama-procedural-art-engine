# 15 — Glossário

| Termo | Definição |
|---|---|
| 2.5D | Apresentação visual 2D com percepção de profundidade ou mundo espacial, normalmente combinando elementos 2D e 3D |
| Atlas | Imagem que reúne várias regiões/frames de textura |
| BuildManifest | Registro dos componentes e versões usados para construir um personagem |
| CharacterSpec | Contrato central que descreve identidade e configuração do personagem |
| Concept art | Referência visual de exploração e aprovação artística |
| Frame | Um quadro individual de uma sequência de animação |
| GLB | Formato binário baseado em glTF para intercâmbio de cenas e modelos 3D |
| glTF | Formato de intercâmbio de assets 3D |
| Job | Unidade de trabalho assíncrona, com estado, logs e resultados |
| Pivot | Ponto de referência usado para posicionar/alinha o sprite |
| Provider | Adaptador para um serviço ou modelo externo/local |
| Rig | Esqueleto e estrutura de controles que permitem animar o modelo |
| Rig Profile | Definição de compatibilidade e estrutura de um rig |
| Render Profile | Configuração versionada de câmera, luz, resolução e saída |
| RGBA | Modelo de imagem com canais vermelho, verde, azul e alpha |
| Sprite | Imagem 2D utilizada como representação visual de personagem ou objeto |
| Spritesheet | Imagem ou conjunto organizado de frames de animação |
| Vertical slice | Pequena fatia funcional que atravessa as principais camadas do produto |
| Worker | Processo responsável por executar uma tarefa fora do fluxo principal da interface |
